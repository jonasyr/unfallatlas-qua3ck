## Overview

This document describes the use of AI-based tools within the context of this project with machine learning algorithms. The outline follows the QUA3CK process model to illustrate which tools were used for what purpose at each phase of the project.

The QUA3CK model is an iterative process for developing ML solutions. It stands for:
- **Q**: Question
- **U**: Understanding
- **A3**: **A**lgorithm Selection, Data **A**daptation, Parameter **A**djustment
- **C**: Conclusion & Comparison
- **K**: Knowledge Transfer

> All results generated by AI systems (e.g., code, analyses, etc.) were critically reviewed, validated and adapted by me as the responsible developer. I bear full responsibility for the project.

## Data sets that were used

| **Data set**                              | **Source**                                                                                                                            | **Description**                                                                                                                                                                       | **Purpose**                                                                                     |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Unfallatlas Deutschland 2016–2024         | Statistische Ämter des Bundes und der Länder via GovData / Mobilithek — Datenlizenz Deutschland 2.0 (Namensnennung)                   | ~2.09 million police-recorded road accidents in Germany across nine annual vintages; 21 columns including severity class (`UKATGEORIE` 1–3), time, accident type, environmental conditions, vehicle involvement, and GPS coordinates | Primary dataset for multiclass severity classification (target variable: `UKATGEORIE`)          |
| DWD CDC Hourly Observations               | Deutscher Wetterdienst (DWD), Climate Data Center (CDC) — GeoNutzV (uneingeschränkte Nutzung); Attribution: "Quelle: Deutscher Wetterdienst (DWD), Climate Data Center (CDC)" | Hourly station-based meteorological observations from ~530 active German weather stations; variables used: air temperature (TU), precipitation (RR), visibility (VV), wind speed (FF) | Weather feature enrichment: four additional predictors joined to each accident record by nearest station (≤ 30 km) and hour of occurrence |
